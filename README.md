# Akara — Watch. Explain. Learn.

> A Feynman voice loop + Manim explainer library for NCERT grades 6–12.
> Students watch a short animated explainer, then prove understanding by
> **explaining it back out loud** while a Socratic voice tutor probes the gaps.

Built for Indian government-school students (grades 9–12, Physics / Chemistry /
Maths / Biology) — noisy classrooms, cheap phones, and Hindi / Hinglish /
regional languages as first-class citizens.

---

## How it works

```
┌──────┐  picks topic + language   ┌─────┐  mints LiveKit token + TopicData  ┌──────────┐
│ Web  │ ────────────────────────▶ │ API │ ────────────────────────────────▶ │ LiveKit  │
│ SPA  │                           │     │                                    │  room    │
└──┬───┘                           └──┬──┘                                    └────┬─────┘
   │ watches Manim video              │ seeds catalog (2,027 concepts)            │ voice agent:
   │ from R2 / CDN                    │ scores transcripts, queues quiz jobs      │ VAD → STT → LLM → TTS
   │                                  │ renders videos via video service          │ one gap-targeted question/turn
   ▼                                  ▼                                           ▼
Explainer library ◀──────── 5-stage video pipeline ───────── transcript.json → scorer → coverage → progress
(Manim + Azure TTS → R2 → webhook callback)
```

The core loop is **Watch → Explain → Score**:

1. **Watch** — a short Manim explainer video (Hindi / English / regional), rendered by the video pipeline and served from R2.
2. **Explain** — the student joins a LiveKit room and explains the concept back; the voice agent (VEXYL-STT + LLM) asks one Socratic follow-up per turn.
3. **Learn** — the transcript is scored for coverage/mastery, progress is recorded, and on-demand quizzes/flashcards are generated by the worker.

Deliberate design choice: no RAG tool and no Score tool inside the voice hot
path — scoring happens after the room ends. See
`docs/architecture/architecture.md`.

## Features

- 📚 **NCERT catalog** — ~2,027 concepts across 239 chapters, seeded from `packages/akara_db/syllabus.json`
- 🎬 **Explainer video pipeline** — 5-stage Manim + Azure TTS render → Cloudflare R2 → webhook callback
- 🎙️ **Feynman voice tutor** — LiveKit agent (Socratic, Hindi/English/Hinglish), self-hosted STT
- 🗣️ **Indic STT** — vendored VEXYL-STT server (AI4Bharat IndicConformer 600M), CPU or CUDA
- 🧠 **LLM scoring + quiz generation** — arq worker (Azure OpenAI scorer, on-demand quizzes/flashcards)
- 📊 **Progress tracking** — mastery, points, activity heartbeats, generation status per concept/language
- 🔐 **Auth** — email/password + Google OAuth (GIS `id_token` flow)
- 🌐 **Multilingual** — Hindi, English, and regional languages (e.g. Punjabi)

## Quickstart

### Prereqs

- Python ≥ 3.11, [`uv`](https://docs.astral.sh/uv/), Docker Desktop, Node 20+, `openssl`
- Verify: `python --version && uv --version && docker --version && node --version`

### 1. Clone + env

```sh
git clone https://github.com/rachitgoyal14/akara.git
cd akara
cp .env.example .env.local
openssl rand -hex 32   # → paste as JWT_SECRET in .env.local
openssl rand -hex 32   # → paste as WEBHOOK_SECRET in .env.local
```

Minimum `.env.local` to boot:

```sh
JWT_SECRET=<from-openssl>
WEBHOOK_SECRET=<from-openssl>
HF_TOKEN=hf_...   # REQUIRED on fresh machines: gated
                  # ai4bharat/indic-conformer-600m-multilingual (~2.4 GB, first STT boot)
DATABASE_URL=postgresql+psycopg://akara:akara@localhost:5432/akara
ASYNC_DATABASE_URL=postgresql+asyncpg://akara:akara@localhost:5432/akara
REDIS_URL=redis://localhost:6379/0
```

Full features (see `docs/operations/secrets.md`): `LIVEKIT_URL` / `LIVEKIT_API_KEY` /
`LIVEKIT_API_SECRET`, R2 (`R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`,
`R2_BUCKET`, `MEDIA_CDN_BASE`), Azure OpenAI (`AZURE_OPENAI_ENDPOINT`, `AZURE_API_KEY`,
`AZURE_OPENAI_DEPLOYMENT`), Azure Speech (`AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`),
`GOOGLE_CLIENT_ID`.

### 2. Run the full stack

```sh
docker compose up -d --build            # web + api + worker + video + stt + postgres + redis
docker compose --profile voice up -d    # + LiveKit voice worker
docker compose ps
docker compose logs -f api              # first boot seeds the catalog
docker compose logs -f stt              # first boot downloads the model; wait for "model ready"
```

| Service | URL |
|---|---|
| App | http://localhost |
| API docs | http://localhost:8000/docs |
| API health | http://localhost:8000/health |
| Video health | http://localhost:8001/health |
| STT health | http://localhost:8091/health |

### 3. Smoke-test the API

```sh
curl -X POST http://localhost:8000/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"name":"Test","email":"t@t.com","password":"password123"}'
export TOKEN=<token-from-above>

curl http://localhost:8000/api/users/me/profile -H "Authorization: Bearer $TOKEN"
curl "http://localhost:8000/api/curriculum/subjects?class=10" -H "Authorization: Bearer $TOKEN"
curl http://localhost:8000/api/library/summary -H "Authorization: Bearer $TOKEN"
curl http://localhost:8000/api/progress/summary -H "Authorization: Bearer $TOKEN"
```

## Development

### Frontend

```sh
npm --prefix apps/web install
npm --prefix apps/web run dev      # http://localhost:3000 (needs VITE_API_BASE=http://localhost:8000)
npm --prefix apps/web run lint     # tsc --noEmit
npm --prefix apps/web run build
```

Frontend-only env (`apps/web/.env`, Vite dev):

```sh
VITE_API_BASE=http://localhost:8000
VITE_GOOGLE_CLIENT_ID=<...>.apps.googleusercontent.com
```

### Backend

```sh
uv sync
uv run pytest -q                                            # full suite
uv run pytest tests/test_api.py tests/test_contracts.py tests/test_scorer.py -q
uv run ruff check .
```

### Database

Migrations are **not** auto-run (the `migrate` compose service runs `alembic upgrade head` on boot; run it manually after schema changes):

```sh
uv run alembic upgrade head
# manual reseed (wipes catalog, keeps users):
uv run python scripts/seed_curriculum.py && uv run python scripts/seed_gold_topics.py
```

### Stop

```sh
docker compose down        # add -v to wipe pgdata + STT model cache
```

## Configuration reference

| Key | Required | Used for |
|---|---|---|
| `JWT_SECRET` (≥ 32 chars) | ✅ | Auth tokens (fail-fast in production) |
| `WEBHOOK_SECRET` (≥ 16 chars) | ✅ | Video-service callbacks |
| `HF_TOKEN` | ✅ (fresh STT boot) | Downloading the gated IndicConformer model |
| `DATABASE_URL` / `ASYNC_DATABASE_URL` | ✅ | Postgres (compose defaults work locally) |
| `REDIS_URL` | ✅ | Job queue (compose default works locally) |
| `LIVEKIT_URL` / `KEY` / `SECRET` | voice | Voice tutoring rooms |
| `R2_*` + `MEDIA_CDN_BASE` | video serving | Rendered-video storage + CDN |
| `AZURE_OPENAI_*` | scoring/quiz gen | Scorer LLM + quiz generation |
| `AZURE_SPEECH_KEY` / `REGION` | TTS | Video narration |
| `GOOGLE_CLIENT_ID` (+ `VITE_GOOGLE_CLIENT_ID` at web build) | Google auth | OAuth login |

> ⚠️ Never commit `.env.local` — it's gitignored. Live values stay on machines, not in the repo.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `relation "subjects" does not exist` | `uv run alembic upgrade head` |
| nginx 502 on `/api/*` after recreating api | `docker compose up -d --build web` |
| TTS "Azure Speech key or region not set" | set `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION` |
| R2 callback 404 | `X-Webhook-Secret` must match; echo render `video_id` |
| genstatus stuck `pending` > 20 min | auto-swept on next poll; poll again to re-trigger |
| STT first boot is slow | expected — ~2.4 GB model download, then cached in the `stt_models` volume |
